## Usage

<code>[LeanLitStr]()[*s*]</code> represents a Lean string literal *s*.

## Details & Options

- *s* is a Wolfram string. It renders as a quoted Lean string.

## Basic Examples

A string literal:

```wl
LeanLitStr["hello"]
```
